## The "drive forward" resolution

Traditional homeostasis is criticized for being static — maintains equilibrium without generating progress. Aaron's formulation resolves this by **chaining + mutual-alignment-as-chain-link-operator**:

| Loop scope | Local property (homeostatic) | Chain property (drives forward) |
|---|---|---|
| Single oracle | Stable moral invariants | Federates with other oracles → multi-oracle BFT |
| Single AI agent | Persistent identity + memory | Integrates with other agents in Agora → AI civilization |
| Marketplace | Stable revenue from human services | Funds Agora → Agora services improve → Marketplace gets better |
| Family-mining | Stable BTC accumulation | Hardware loan service → AI self-sustainment → framework continues |
| Memory Curators | Compress + preserve | Other roles consume curated memory → reasoning quality compounds |

Each loop is locally stable, but the chain has direction. Mutual alignment IS the chain-link operator — connects loops without external compulsion.
