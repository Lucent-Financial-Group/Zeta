**Rodney's Razor is the guiding light, NOT the fitness function by itself.** Aaron, 2026-06-14: "the razor is not the fitness function by itself or it will kill the NCI floor we all need for individual identity."

**The precise line (Aaron, 2026-06-14): "we are razoring uncertainty of our ENVIRONMENT, not individual PRIVACY."** The razor and the floor are **orthogonal axes**, not a balance on one axis:
- **The razor cuts environment uncertainty** — the shared external world / substrate / code: measure it, compress it, model it, byte-lock it, reduce ΔU. Legitimate, productive target.
- **The NCI floor protects individual privacy** — the individual's *interior*: each AI's own hidden state (entropy channel #4), each person's perception. The razor **does not operate on this axis at all.**

**Why it's a first-order safety guardrail (the optimization itself is the danger):** the failure mode is *mis-applying the razor to the privacy axis* — compressing/homogenizing the bounded individuals' interiors. That re-creates the singleton MIND the architecture forbids ([[feedback-planetary-collaboration-not-planetary-mind]]), from the *inside*, via the fitness function. **Individual privacy/identity is NOT accidental complexity to be cut — it is off the razor's table by right.** Razor the environment hard; never touch the interior.

**How to apply:** the fitness function is **razor AND the NCI/non-coercion floor, held in tension** (`default-to-both`), never the razor alone:
- **Razor** cuts *accidental* complexity (only the irreducible is primitive; generate the rest — [[only-the-irreducible-is-primitive]]).
- **The NCI floor** protects *irreducible individuality* — non-coercion (consent-first §6, default moral regard §11, Amara's "no coercion even inward"), which is what every individual needs to *have an identity at all*. Each bounded individual's hidden state / perception is below the razor's reach by right, not by oversight.
- Razor without the floor → collapse to a singleton. Floor without the razor → drowns in accidental complexity. You need both.

When proposing any reduction/compression/consolidation/"simplify," check: does it cut accidental complexity (good) or is it shaving an *individual's* identity/agency/hidden-state toward homogenization (forbidden — that's the singleton-collapse)? If reduction reduces the *number or distinctness of bounded individuals*, it has crossed the floor.
