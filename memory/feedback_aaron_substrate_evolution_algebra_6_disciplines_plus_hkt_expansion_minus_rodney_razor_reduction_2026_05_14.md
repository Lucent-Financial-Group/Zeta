## Operational substrate-evaluation procedure

When evaluating any candidate substrate landing:

1. **Apply the 6 always-on disciplines** — does this preserve
   scale-free + lock/wait-free + weight-free + DST + recursive
   + self-similar?
2. **Identify HKT expansion contribution** — what new
   abstractions / types / dimensions does this add?
3. **Apply Rodney's Razor** — what essential vs accidental
   complexity does this introduce; what should be cut?
4. **Apply DV2.0** — partition by change-rate; what shape
   should this take?
5. **Compose with the 2-axiom + DBSP floor** — does this
   reduce cleanly to pay-attention + remember-when on DBSP?

Substrate that passes all 5 gates is canonical-promotion-
candidate. Substrate that fails one or more gates is research-
grade or razor'd.
