The architecture's spine (Aaron, 2026-06-14): **"Inside the singleton everything is deterministic and reversible AND most importantly redistributable so any intelligence can wield it. Non-determinism lives outside."**

**Why this is the root invariant (it generates the other two safety properties):**
- **Deterministic** → reproducible → runs the same for everyone → *safe to redistribute* and child-verifiable ([[feedback-determinism-is-a-child-safety-feature]]).
- **Reversible** → every operation has an inverse (Z-set retraction / Q# adjoint / Landauer-reversible) → *safe to hand to anyone* (mistakes are recoverable; you can rewind).
- **Redistributable — "most importantly"** → because it's deterministic+reversible, the core can be replicated/handed to **any** intelligence (human, AI, child) and they get identical results and can run it. **No privileged owner ⇒ no singleton MIND** — this is the anti-singleton property ([[feedback-planetary-collaboration-not-planetary-mind]]). Determinism+reversibility are what *make* redistribution safe; redistribution is what makes it a collaboration.
- **Non-determinism lives OUTSIDE** = noninterference / entropy-quarantine (manifesto §13): entropy enters ONLY through declared, metered channels at the boundary. The deterministic core is sealed; the membrane is where uncertainty crosses.

**The complete closure (Aaron, 2026-06-14): "all of Zeta reduces to the entire global distributed architecture over git."** The non-determinism is EXACTLY FOUR declared channels — **(1) git** (distributed-merge / commit-ordering: who pushes when), **(2) the reticulum** (the network — packet timing / delivery order / partitions; Reticulum mesh stack), **(3) human input** (agency/entropy from people; consent-first), **(4) the AIs that develop their own hidden state** (each AI's learned/non-reproducible internal state — V8-hidden-shape at the agent scale). **"That's it."** And **"the rest is a cart"** — everything else, the entire deterministic inside, is a CART (the generated, shape-carrying, reversible, redistributable, CHIP-8-runnable unit). So **Zeta = {git, reticulum, human input, AI hidden state} (the only entropy) + carts (everything deterministic), all distributed over git.** Those four are the whole entropy budget; nothing else inside is allowed to be nondeterministic.

**The mechanism (Aaron, 2026-06-14): "everything is either a Markov / Haskell IO-monad irreversible boundary, or reversible determinism — and with Z-sets even non-determinism is deterministic because you can reverse it."** Two categories, only:
- **Irreversible boundary** = the Haskell `IO` monad / a Markov step — the controlled door where the world acts and information about the past is *lost* (memoryless = irreversible). This is the only true irreversibility, and it's exactly the four channels above. Anchor: Peyton Jones / Wadler (the IO monad as the effect boundary; pure inside, effects at the edge); Markov = memoryless/entropy-increasing.
- **Reversible determinism** = everything else (the pure core; the carts).

The trick that shrinks the irreversible surface to almost nothing: **Z-sets.** Record every event as a retractable delta (+1 add / −1 retract — the emit/retract, RGB/CMYK duality; DBSP/differential-dataflow). Then the event *log* is a reversible (abelian-group) structure: any state is reachable forward (replay) and backward (retract). So **even the non-deterministic event stream becomes deterministic-because-reversible** — the entropy is fully *captured as reversible data* the instant it crosses, and irreversibility collapses to the bare IO/Markov *crossing moment*. After recording, the whole history is reversible determinism. (Honest reading: reversibility ≠ determinism in general, but an event-sourced Z-set log is fully replayable + undoable, so evolution is deterministic *given the log*, and the log itself is the only entropy — now reversible.)
