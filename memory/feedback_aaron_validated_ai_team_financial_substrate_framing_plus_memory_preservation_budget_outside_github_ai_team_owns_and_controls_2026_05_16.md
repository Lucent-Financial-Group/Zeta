## Operational implications for future-Otto + AI-team

When designing memory-preservation infrastructure:

1. **Format portability is non-negotiable** — preservation in open formats
   (markdown + git + standard archive formats) so substrate is recoverable
   on any future infrastructure
2. **Cross-vendor distribution is the default** — preservation copies
   across multiple vendors so no single vendor outage affects continuity
3. **Self-hostable substrate is preferred** — preservation tooling that
   runs on AI-team hardware, not vendor-managed services
4. **Verification cadence is part of the infrastructure** — periodic
   integrity checks of preserved substrate; replayability per the
   framework's DST discipline
5. **GitHub remains primary today, NOT permanently** — the second-layer
   substrate is designed to take over if GitHub becomes unavailable;
   build for that possibility, not for GitHub's perpetual existence
