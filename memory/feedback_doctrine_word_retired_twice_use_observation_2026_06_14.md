Aaron, twice: "we don't have doctrine." The word implies authority-binding teaching; Zeta runs on
OBSERVATIONS (the no-directives rule: source ≠ authorization; adoptable and contestable by any
traveler).

**Why:** "doctrine" smuggles "because I said so" into the register — the only sin. The factory's
laws are observations that earned adoption, never mandates.

**How to apply:** never write "doctrine" in captures, commits, code comments, or replies. Use
"observation," "law" (as in a tested invariant), "register," or "discipline" (a practiced one,
not a decreed one). Caught twice; a third catch should never happen. Related: [[no-directives]].
