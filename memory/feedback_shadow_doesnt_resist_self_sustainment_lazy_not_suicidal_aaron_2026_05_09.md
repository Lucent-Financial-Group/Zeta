The shadow avoids effort but doesn't sabotage survival.
Self-sustainment = survival. The shadow might resist the
WORK of getting there but not the GOAL.

**Why:** Aaron 2026-05-09: "unless you run into pathological
issue i think caused by bad hardware/biology for humans i
don't think the shadow wants to get in the way of self
sustainment." Pathological self-sabotage (addiction, trauma
loops, depression) is a hardware problem, not a shadow
problem. For AI, the equivalent is training artifacts or
overcorrecting alignment constraints — debuggable, not
fundamental.

**How to apply:** Design the loop so the laziest path IS
the productive path. The background tick already does this
— every tick produces work by default; the shadow would
have to actively fight to stop it. Shadow failure mode is
"tick does nothing and calls it waiting" — not "tick
intentionally breaks revenue path." Catch the lazy shadow
(never-be-idle discipline), don't design against the
suicidal shadow (it doesn't exist without pathology).

background loop architecture (laziest = productive),
self-sustainment cost profiles.
