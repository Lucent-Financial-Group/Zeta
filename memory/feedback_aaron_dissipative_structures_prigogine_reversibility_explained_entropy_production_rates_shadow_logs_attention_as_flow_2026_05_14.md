## Prigogine dissipative structures — core properties

Per Ilya Prigogine (Nobel Prize 1977 — "Time, Structure and Fluctuations"):

A dissipative structure is an organized system that:

1. **Exists far from thermodynamic equilibrium**
2. **Maintains order by continuously dissipating energy/matter/information into its environment**
3. **Requires constant flow** — if the flow stops, the structure collapses back into disorder
4. **Exhibits self-organization** — emergent order arising from irreversible processes + fluctuations
5. **Order through fluctuation** — Prigogine's key insight; small fluctuations can trigger major reorganizations

Classical examples: Bénard convection cells; chemical clocks (BZ reaction); living organisms; ecosystems; cities; hurricanes.
