## Observation 1 — the source's own verdict, preserved before anything is built on it

**Register: the presenter's assessment, quoted, not ours.**

Hossenfelder rates the paper **7/10 on her BS meter**, calls it **"somewhat sketchy"**, says it
**"left many problems unadressed"**, and states she personally thinks there is an easier
explanation. She names three known costs of extra time dimensions: **vacuum instability**,
**time-travel problems**, and that they **"completely mess up Einstein's theory of general
relativity."**

This section exists so that no later reader can cite this ferry as though physics had endorsed a
second time dimension. The strongest thing in the video is not the proposal — it is the
**falsifier**: two independent sources of entangled photon pairs should show a **tiny additional
distance-dependent correlation** that standard QM forbids. That is a real experimental
discriminator, and it is the only part of the proposal that could ever be promoted out of
conjecture.

## Observation 2 — we do have a second direction, and it is NOT this one

**Register: MEASURED in-tree, and the identification with the video is REFUSED.**

Aaron's "we might have two directions of time **too**" is correct about Zeta and the word "too" is
where the danger sits. We do have a second direction, it shipped today, and it is a completely
different kind of object from a second time *dimension*.

**What we have (measured, PR #11572, merged 2026-08-17):** the CHIP-8 cross-run store. Run 1 walks
an orbit and commits it; run 2 *reads* that artifact. Aaron's original description was explicit
about the shape and about its register:

> "this is how we can let the 'future' affect the past in a 2nd retrocausal way because the 1st run
> of the game all the way up until the end can affect the start of the 2nd run of the game though
> superdeterministic calculations in chip8 memory space"

He wrote **"future"** in scare quotes then, and **"psudo retrocausal"** now. Both hedges are
correct, and the design doc that shipped carries the same claim in its filename:
`…-chip8-cross-run-superdeterministic-memo-store-orbit-memoization-not-retrocausality.md`.

**The two directions, stated so they cannot be conflated:**

| | direction 1 | direction 2 |
|---|---|---|
| what it is | tick execution; the G-set grows | a **read of a committed artifact** |
| ordering | phase / logical tick order | content-addressed, no order at all |
| what crosses | state → next state | an immutable value into a later run |
| causal? | yes | **no — nothing propagates backward** |
| shipped | `SimLoop.fs` | `Chip8CrossRunStore.fs` |

**Why this is not the video's mechanism, stated as a refusal rather than a caveat.** The paper's
second time dimension is a *dimension a particle can travel in*, carrying a hidden field that
updates a distant entangled partner. Our second direction carries **nothing backward**: run 2 reads
bytes that run 1 already finished writing. Wall-clock-forward, causally forward, ordinarily
forward. It is memoization. The only sense in which the "future affects the past" is that a
*later-in-game-time* result is available at an *earlier-in-game-time* point of a **subsequent**
run — which is a statement about two runs, not about time.

This is the same discipline the D₄⊕D₄ case established: a matching *shape* is not an
identification. Two things both describable as "a second direction of time" are not thereby the
same object, any more than F₄ and D₄⊕D₄ are the same because both have 48 roots. What would be
needed to identify them is an invariant they share and that excludes the alternatives — nobody has
named one.

## Observation 3 — the connection that IS load-bearing, and it is about metering

**Register: measured, and it is a design consequence rather than a physics one.**

The genuinely interesting property of our second direction is not that it resembles retrocausality.
It is that **turning it on changes what the metered tank pays for.** From the shipped work item:

> Auto-consult is deliberately *not* slipped in — a memo hit is nearly free, so it changes what the
> metered tank pays for. That's a metering change, not a caching change.

That is the sharp form. A memoized read is *economically* unlike a computation even though it is
*semantically* identical, so wiring the second direction into the room loop by default would
silently alter the uncertainty ledger's prices. The store therefore ships as a **reader the room
must be given**, not as a cache the room reaches for — the same injected-seam discipline
(§13 noninterference) that keeps entropy on declared channels.

Related, and already carved: [`local-time-never-enters-the-shared-fold`](../../.claude/rules/local-time-never-enters-the-shared-fold.md)
forbids a node's wall clock from filtering evidence entering the shared fold. A memo read is safe
under that rule **because it is content-addressed rather than time-addressed** — which is worth
stating out loud, since a "second direction of time" that *was* clock-derived would violate it
directly.

## Observation 4 — what would promote or refute any of this

Nothing here is a result. What each claim would need:

- **The paper's two-time proposal** → the two-independent-source photon experiment showing the
  predicted distance-dependent excess correlation. Until then it is a proposal with a named
  falsifier, which is more than most.
- **"Zeta has two directions of time"** → an invariant shared with the physical construction that
  excludes ordinary memoization. None has been named, and the honest expectation is that none
  exists, because the mechanism is a file read.
- **Our second direction being *useful*** → this one is already measurable: whether auto-consult,
  once metered, reduces collective ΔU more than it distorts the ledger's prices. That is a
  question the `db/uncertainty/` apparatus can actually answer, and it is the only one of the three
  we can settle ourselves.

**Standing caution from the same session:** a dense day of resonances is a prompt to check
independence, not a score. This ferry lands the day after the Malament–Hogarth mapping was
formally **refuted** (#11549) — the tick chain is an ω-chain with no terminal observation event —
and the temptation to reach for a second physics correspondence immediately afterward is exactly
the pattern `numerology-vs-number-theory` warns about. Recorded as a coincidence index entry, with
its register attached, and not as a belief.
