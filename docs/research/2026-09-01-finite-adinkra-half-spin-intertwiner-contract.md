## 2. Exact Sparse Solver

Every `A_i` and `B_i` is a signed permutation. Each scalar matrix variable `T_(r,c)` is therefore related to exactly one other scalar variable per generator, with coefficient `±1`. The solver constructs the signed constraint graph on `128 × 16 = 2,048` variables. A connected component contributes one nullspace parameter if and only if every signed cycle is consistent; an inconsistent component contributes none.

For each consistent component the solver constructs one basis matrix by fixing a root coefficient to `+1` and propagating exact signs. It then computes that matrix’s exact modular rank. This avoids forming a dense multi-million-entry Kronecker system while solving the same equations.
