<h2>v1.32.0</h2>
<p>The 1.32 release of the QDK is packed with new features and capabilities, along with numerous bug fixes and performance improvements. Highlights include new interactive learning content for quantum chemistry, a Bloch sphere visualizer, QDK-Stim support, non-Clifford stabilizer simulation, the new Q# <code>parallel</code> keyword, improved circuit rendering, and more.</p>
<h3>QDK Learning Chemistry notebooks</h3>
<p>We've expanded our learning content with a new <strong>Ground-state molecular energies with quantum phase estimation</strong> tutorial for the <a href="https://microsoft.github.io/qdk-chemistry/">qdk-chemistry</a> library. The course consists of several notebooks that are tightly integrated with advanced VS Code and GitHub Copilot features. (See the docs at <a href="https://aka.ms/qdk">https://aka.ms/qdk</a>, or the walkthrough videos at <a href="https://aka.ms/qdk.install">https://aka.ms/qdk.install</a> and <a href="https://aka.ms/qdk.copilot">https://aka.ms/qdk.copilot</a>, for details on setting up VS Code, Python, and GitHub Copilot).</p>
<p>To get started, open a directory in VS Code where you'd like to save your progress, and ensure you have a Python environment with the <code>qdk-chemistry</code> package installed. (The new <strong>QDK Python environment creation</strong> command, described below, can help with this). Then go to the <strong>Microsoft Quantum</strong> area in the Activity Bar and select <strong>Start Learning</strong>. This adds both the Katas and Chemistry courses to your workspace, ready for you to work through at your own pace.</p>
<!-- raw HTML omitted -->
<p>Note: If using a <strong>qdk-chemistry</strong> version earlier than 2.2, Python for Windows is not supported. On Windows, you must be using the Windows Subsystem for Linux (WSL) to install the required <strong>qdk-chemistry</strong> Python dependencies.</p>

A new VS Code command creates a virtual environment named <code>.venv</code> in the current workspace and installs the QDK packages you select. This is especially useful for setting up the QDK Chemistry learning experience described above - just make sure <code>qdk-chemistry[jupyter]</code> is selected.</p>

<h3>Bloch sphere visualizer</h3>
<p>This release also introduces an interactive <strong>Bloch sphere visualizer</strong>, providing a new way to explore and understand single-qubit states and operations. In VS Code, launch it from the Command Palette using <strong>QDK: Bloch sphere</strong>. In Jupyter notebooks, use the <code>BlochSphere</code> widget.</p>

<p>The Bloch sphere animates rotations as gates are applied and can also show a trace of the state vector updates as unitary matrices are applied.</p>
<p>Rotations can be applied directly or through <strong>rotation synthesis</strong>, using a sequence of Hadamard and T gates.</p>

<h3>QDK-Stim</h3>
<p>This release introduces experimental support for <strong>QDK-Stim</strong>, a Stim-like language in the QDK. QDK-Stim supports the instruction set made popular by Stim, additional non-Clifford operations similar to those supported by <a href="https://github.com/unitaryfoundation/clifft">Cliftt</a> and <a href="https://github.com/QuEraComputing/tsim">tsim</a>, and several QDK-specific instructions as described below.</p>
