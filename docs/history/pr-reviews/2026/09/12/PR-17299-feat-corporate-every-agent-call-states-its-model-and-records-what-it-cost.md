## Description

## What this measures

A day of Agentic Team runs across three repositories cost about **$3,900** and the organization recorded **none of it**. Reconstructing it from the harness's private transcripts gave the numbers this change is built on:

| | measured, 2026-09-11 |
|---|---|
| unique content ingested | ~6.2M tokens |
| tokens billed as cache reads | **1.46 billion** — a 235× amplification |
| average context re-read per turn | 148k tokens (worst sessions 317k) |
| sessions / turns | 196 / 9,872, averaging 50 turns each |
| re-reads of a path the same session already read | 587 calls, 31% of all read volume |
| screenshots read into context | 18 reads, 2.5M characters of PNG |

## Three gaps, three fixes

**Nobody chose a model.** `--model` was passed only when `ORG_CLAUDE_MODEL` happened to be set; it was set nowhere, so every agent took whatever the installed CLI defaulted to — an Opus build from an npm package 127 releases behind the one the operator was using. A model is now **required**, like every other piece of organization configuration: `ORG_CLAUDE_MODEL_BY_HAT` maps hat → model with an optional `"default"`, `ORG_CLAUDE_MODEL` is the one-model form, and neither set is a refusal rather than a guess. No hat or model name appears in the code; the map is the operator's.

**Nobody recorded the money.** `total_cost_usd` was parsed and thrown away. Each call now appends a line to `<store>/cost/<date>.jsonl` carrying the money *and* its provenance — work item, hat, mode, model, session, and the reason the run was started, which the watcher threads into the run. `cost-ledger.ts` folds it (keyed by session id, so re-reading a day cannot double-count), and `org cost` reports by day, work item, hat, mode, model, profile and reason. A call that reported no cost is counted and named, never read as free; a malformed value cannot turn a total into `NaN`; an unparseable line is reported rather than swallowed.

**What enters context is decided before it does.** The cost of a thing entering context is its size times the turns that follow it. `org-context-guard.cjs` is a `PreToolUse` hook that refuses pictures, whole reads of large files, and a path this session already read — each refusal naming the cheaper route to the same information, so no capability is removed. It fails open, so it can never be why a run stops.

Also lands the red-pipeline policy the same measurement surfaced (an organization never asked what a red pipeline means has not said it does not care), and its reading half — `followup-commands.ts` was setting `ORG_PIPELINE_POLICY` with nothing reading it.

stated rather than inherited from whatever umask happens to be set.

want state somewhere specific. An explicit path the caller chose is not the same
risk as a guessable one the caller never named. Where there is no home directory
