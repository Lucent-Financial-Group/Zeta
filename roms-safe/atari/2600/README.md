# Safe Atari 2600 ROMs

This directory contains Atari 2600 ROMs that have been identified as safe to distribute, based on their public domain, freeware, or permissive homebrew licenses.

The list of safe ROMs is maintained in `tools/roms/manifests/atari-2600-allowlist.txt`. The `tools/roms/split-by-license.ts` script is used to automatically move ROMs from the gitignored `roms/atari/2600` directory to this directory.
